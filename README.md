A one-line review of the most boring everyday object — the pencil eraser, rubbing out other people's mistakes until there's nothing left of it. One line, 160 characters, funny because it's true: the better the eraser does its job, the smaller it gets.

Bounty: [The Most Boring Object, Reviewed in One Line](https://make.fun/competitions/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)

## Run it

```sh

```

Writes the review to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when the harness sets it), with no trailing newline.
